TUTORIAL :
ROLarp is A browser extension that allows you to change the way your Robux balance is displayed on Roblox.

📥 Installation
Download this GitHub repository.
Extract the archive if necessary.
Open your browser's extensions page.
Enable Developer mode in the top-right corner.
Click Load unpacked.
Select the folder containing the Roblox Larp files.
The extension is now installed.
💰 How to Use
Log in to Roblox.
Click on the extension icon in your browser.
Enter the number of Robux you want to display.
Click Generate.
Go back to the Roblox page and refresh it using F5 or Ctrl + R.
The displayed Robux amount will then be changed.

🔄 Refreshing the Page
You can continue refreshing the Roblox page. The Robux amount configured with the extension will remain displayed after refreshing.

⚠️ Important
This extension only changes the display on your browser.
